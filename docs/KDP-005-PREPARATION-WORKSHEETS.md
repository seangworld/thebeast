No worksheet marks cover, metadata, pricing, originality, rights, factual review or AI disclosure evidence complete. The files make the remaining work explicit and portable; they do not create a cover image, verify current KDP terms, select an ISBN, access Amazon or authorize submission.

Before package approval, the owner must complete and record every applicable review, use the current KDP cover and royalty/printing-cost tools, preview each uploaded format and confirm the final account choices.
