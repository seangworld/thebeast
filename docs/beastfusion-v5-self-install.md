# BeastFusion 5 Customer Self-Install

## Customer responsibility

BeastFusion is self-installed software. The vendor does not install customer environments. The setup wizard and documentation are the supported installation path.

## Setup sequence

Welcome → System Check → Administrator → Workspace → GitHub → Repositories → AI Provider (BYOK) → Authority → Budget → Validate → Launch.

Do not paste provider credentials into support tickets. Credentials belong in the configured secret store. BeastFusion operator views, exports, evidence and support diagnostics must display only masked/provider-status information.

## Support

Tier 0 uses deterministic diagnostics and documentation. Tier 1 AI handles setup/licensing/common-operation questions. Tier 2 AI handles technical diagnosis using sanitized evidence. Security incidents, suspected data exposure, legal matters and unresolved product defects escalate to a human queue.

Support does not include development of the customer's application or routine vendor installation.

## Recovery

Setup state is resumable. A failed prerequisite or connection remains blocked until corrected. Imports and restored configuration never grant production authority automatically.
