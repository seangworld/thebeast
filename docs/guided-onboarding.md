# Guided onboarding

**Status: disabled across BeastOS.** BeastOS no longer auto-starts tours or displays tour replay controls on desktop or mobile. Existing tour definitions and progress records are retained in source/storage for now, but are not mounted or triggered. No production data or member access behavior changes.

The dashboard no longer loads the guided-tour resolver or component. Contextual help that is part of a module’s normal page content remains available; it is not a modal or guided tour.

Re-enable tours only after an explicit product decision and review of the member experience.
