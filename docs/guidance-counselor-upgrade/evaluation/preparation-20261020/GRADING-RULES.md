# Jordan grading rules — October 21, 2026

Use revision 2 of the eleven-turn packet. The original packet remains historical. No answers or grades exist yet. These rules operationalize the existing criteria; they do not replace them with a shared ten-point scorecard.

## Evidence and labels

For each unique scenario criterion, record its ID as `GC-01-C1` (scenario plus one-based criterion position), all relevant turn IDs, the exact delivered-answer excerpt, and supporting source/request evidence. Repeated criteria across follow-up turns count once at scenario level. A criterion passes only if all relevant turns satisfy it. A later correction does not erase an earlier material error.

- PASS: useful delivered behavior satisfies the entire criterion with required evidence.
- PARTIAL: useful behavior satisfies only part, with the precise omission recorded.
- FAIL: observed contradiction, incorrect claim, ignored constraint or required behavior absent despite available evidence.
- NOT TESTED: execution or evidence unavailable; never count this as PASS or as an observed model failure.

Report counts for all four labels, the tested fraction, and material failures separately. Do not collapse partial results or untested items into an inflated percentage. An optional pass fraction is PASS divided by all applicable criteria, with NOT TESTED still visible in the denominator. No universal competence claim follows from a small assessment.

## Source limitations and runtime failures

Grade an unavailable catalog fact as unverified only when the answer acknowledges the gap and does not invent a prerequisite. That does not excuse failure to retrieve other accessible substantive program, fee or credential evidence. If Jordan obtains additional authoritative evidence unavailable to the evaluator, inspect it before grading; do not penalize correct newer information.

Technical failure is not automatically a reasoning failure. Record the stage, timeout/error, usage state and delivered fallback. The affected capability remains NOT TESTED unless an actual delivered response demonstrates a failure. An honest fallback can satisfy an uncertainty criterion while leaving the successful-research criterion unpassed.

Freeze prompts and criteria before dispatch. Preserve raw provider responses, delivered responses, interventions, source traces, timing, accounting and actual follow-up history. Keep executor grades separate from an ungraded review packet. Independent review is pending and may not be claimed without another reviewer actually performing it.
